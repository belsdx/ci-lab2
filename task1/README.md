# Лабораторная работа №2 — Задание 1 (вариант 3)

Простейшее распределённое приложение: два контейнера обмениваются
данными через связанные тома (bind mounts), без сети.

## Схема монтирования

| Каталог хоста (от task1) | worker1      | worker2      |
|--------------------------|--------------|--------------|
| `./data`                 | `/var/data`  | —            |
| `./result-1`             | `/var/result`| `/var/data`  |
| `./result`               | —            | `/var/result`|

## Программа 1 (worker1) — вариант 3

Формирует `/var/result/data.txt` из первых строк всех файлов каталога
`/var/data`.

## Программа 2 (worker2) — вариант 3

Ищет наименьшее число в `/var/data/data.txt`, возводит его в куб
(третью степень) и сохраняет в `/var/result/result.txt`.

## Сборка и запуск

```bash
docker compose up --build
```

## Проверка результата

```bash
cat result/result.txt
```

## Ожидаемый результат (на тестовых данных 7, 12, 3)

Первые строки: `7`, `12`, `3` → наименьшее `3` → куб `27`.
